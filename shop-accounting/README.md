# ระบบบัญชีธุรกิจร้านค้า (Shop Accounting System)

ระบบบัญชีครบวงจรสำหรับธุรกิจร้านค้า — จัดการสินค้า ออกเอกสารขาย และลงบัญชีคู่อัตโนมัติ

## ✨ Features
- **จัดการสินค้า** — SKU, ราคาทุน/ขาย, สต็อก, จุดสั่งซื้อ, สินค้าประเภทบริการ
- **เอกสารครบชุด** — ใบเสนอราคา → ใบแจ้งหนี้ → ใบส่งสินค้า → ใบกำกับภาษี → ใบเสร็จ
- **แปลงเอกสารในคลิกเดียว** — ไม่ต้องพิมพ์ซ้ำ พร้อม trace ย้อนกลับได้
- **ลงบัญชีคู่อัตโนมัติ** — ทุกเอกสารที่อนุมัติจะสร้าง Journal Entry ให้เอง
- **ภาษีไทยครบ** — VAT 7%, ภาษีขายรอเรียกเก็บ, หัก ณ ที่จ่าย 1/2/3/5%
- **รายงาน** — งบกำไรขาดทุน, งบทดลอง, Dashboard ภาพรวม
- **พิมพ์เอกสาร** — CSS print-ready ไม่ต้องพึ่ง library PDF

## 🚀 Quick Start

```bash
git clone https://github.com/<your-username>/shop-accounting.git
cd shop-accounting

npm install
cp .env.example .env

docker compose up -d      # เปิด PostgreSQL
npm run setup             # สร้างตาราง + ใส่ข้อมูลตัวอย่าง
npm run dev
```

เปิด http://localhost:3000

## 🧮 หลักการลงบัญชี

| เอกสาร | เดบิต | เครดิต |
|---|---|---|
| ใบแจ้งหนี้ (INV) | ลูกหนี้การค้า, ต้นทุนขาย | รายได้จากการขาย, ภาษีขายรอเรียกเก็บ, สินค้าคงเหลือ |
| ใบกำกับภาษี (ต่อจาก INV) | ภาษีขายรอเรียกเก็บ | ภาษีขาย |
| ใบเสร็จรับเงิน (RC) | เงินสด, ภาษีถูกหัก ณ ที่จ่าย | ลูกหนี้การค้า |
| บันทึกค่าใช้จ่าย (BILL) | สินค้าคงเหลือ/ค่าใช้จ่าย, ภาษีซื้อ | เจ้าหนี้การค้า |

> ระบบตรวจสอบ Dr = Cr ทุกครั้งก่อนบันทึก หากไม่สมดุลจะ rollback ทั้ง transaction

## 📌 หมายเหตุสำคัญ

- ตัดสต็อก **ครั้งเดียวต่อ chain เอกสาร** (QT→INV→DN→TI ตัดที่ใบแรกที่อนุมัติ)
- ใช้ `NUMERIC/Decimal` ทั้งระบบ — ไม่มีปัญหา floating point
- ยังไม่มีระบบ Auth — ควรเพิ่ม NextAuth + RBAC ก่อนใช้งานจริง
