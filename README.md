# 🏪 ระบบบัญชีร้านค้า (Shop Accounting)

เว็บแอปบัญชีสำหรับร้านค้าขนาดเล็ก — HTML/CSS/JS ล้วน ไม่ต้อง build

## ฟีเจอร์
- แดชบอร์ดยอดขาย/กำไร/ลูกหนี้
- จัดการสินค้า หมวดหมู่ และสต็อก
- เอกสารขายครบ 5 ประเภท + แปลงเอกสารต่อกันได้
- บันทึกซื้อสินค้าและค่าใช้จ่าย
- รายงาน: งบกำไรขาดทุน, ภาษีขาย, ลูกหนี้คงค้าง, สินค้าขายดี
- พิมพ์เอกสารเป็น PDF ผ่านเบราว์เซอร์
- สำรอง/กู้คืนข้อมูลเป็นไฟล์ JSON
